The Linked Data Event Streams (LDES) implementation reports

This repository contains implementation reports that SEMIC and the community have made to support the use of the LDES specification.

The intention of these reports is to document specific LDES use cases, help the community learn from them, support easy LDES adoption, and address LDES edge cases. The following implementation reports exist:

Implementation Report Description
LDES DCAT-AP feeds Publishing a full data dump over and over again will delegate change detection — a fault-prone process — to data consumers. With DCAT-AP Feeds we propose that DCAT-AP catalog maintainers publish an event source API that can help to replicate the catalog towards a harvester and keep it in sync in the way intended by the publisher. Therefore, this spec describes how to publish your DCAT-AP entity changes using the Activity Streams vocabulary and LDES. It also provides a specification for harvesters to provide transparency into their harvesting progress.
Cultural Heritage Event Streams with LDES This implementation report specifies how cultural-heritage datasets (e.g., artworks, museum objects, vocabularies) can be exposed as incremental event streams using LDES and ActivityStreams. It covers the stream design, versioning, retention policies, activity types (Create/Update/Delete), publisher/consumer real-world instances, and conformance requirements.
ERA DCAT-AP Feed This implementation report is a proof-of-concept RDF-Connect pipeline that generates a DCAT-AP Feed from the European Union Railway Agency’s DCAT-AP metadata. It covers change detection, ActivityStreams event generation, time-based bucketization, and static feed publication via GitLab Pages.
BOSA DCAT-AP Feed This implementation report documents how the Federal Public Service for Policy and Support (BOSA) Belgium publishes the Belgian federal DCAT-AP catalog as a DCAT-AP-Feed using an RDF-Connect pipeline, with deployments both at BOSA’s premises and via GitHub Pages. It also reports on the piveau-consus-importing-ldes plugin developed to enable automatic ingestion of DCAT-AP-feeds into the EU Publications Office’s Piveau catalog management platform.

If you want to share your report or implementation, feel free to open a pull request, file an issue, or contact us at digit-semic-team@ec.europa.eu.

Other known implementations

In addition to the implementation reports, this repository also collects software building blocks and public LDES examples that can be used today. These examples do not necessarily have a full implementation report.
